## Warhammer Score Tracker

https://a4-lukeciarletta.onrender.com/

I updated my Assignment 2 to use Svelte. I also updated the modification feature such that each entry has an ID that the user enters to modify it rather than pressing a modify button. I would say that Svelte improved the development experience. While it took some work to modify it from vanilla JavaScript into Svelte, it would be easier to expand it further from this state. It requires less confusing element manupulation with the DOM, as Svelte is able to handle the updating. It is also more effieicnt, as it does not necessarily have to update the entire page if just one component changes.
